# Checking the OpenCode handoff

1. Open [the backlog](opencode-meal-logging-backlog.md). Verify tasks 1 through 44 appear once, in order, across seven milestones. Compare the milestone index with the numbered sections.
2. Copy the session prompt into OpenCode with the repository open. Confirm its plan addresses the first unchecked task and identifies the delayed preview as the regression to test.
3. For each subsequent implementation, review its own dated QA file and reported results before marking its backlog item complete.
4. Trace one meal from text or photo through clarification, confirmation, the daily diary, and both reports. Check that the tasks specify how to handle missing amounts, missing nutrients, partial days, and provider outages along that path.
